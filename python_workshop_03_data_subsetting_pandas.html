Part 2. Essential pandas subsetting techniques

Read the examples, then apply the same ideas independently in the five exercises. Examples use illustrative variable names, not answers to the assignment.

Operation pandas syntax Purpose
Select columns df.loc[:, ["col_a", "col_b"]] Keep named fields
Select matching names df.filter(regex="pattern", axis=1) Choose columns by name pattern
Filter rows df.loc[df["score"] > 10] Keep observations meeting a rule
Any condition (condition_a) \| (condition_b) Logical OR
All conditions (condition_a) & (condition_b) Logical AND
Values in a set df["group"].isin(["A", "B"]) Match multiple categories
Rename a column df.rename(columns={"old": "new"}) Improve variable clarity
Export df.to_csv(path, index=False) Write reusable CSV
TipBoolean filtering: essential syntax

Use &, |, and ~ with pandas Boolean Series, not Python’s scalar and, or, and not. Place each comparison in parentheses. Use == for equality, > and < for numeric thresholds, and .isin(...) for category membership.

Part 4. Validate and document your outputs

In a text cell, briefly report the number of rows and columns in each extract, and explain any surprising result. You can use this compact validation pattern after completing all exercises:

# Run after your five DataFrames have been created.
subsets = {
    "demog_loan_info": demog_loan_info,
    "credit_vars": credit_vars,
    "high_income": high_income,
    "high_risk": high_risk,
    "prime": prime,
}

summary = pd.DataFrame(
    [(name, df.shape[0], df.shape[1]) for name, df in subsets.items()],
    columns=["Subset", "Rows", "Columns"],
)
display(summary)

# Confirm all expected CSV outputs were written.
for name in subsets:
    print(name, (output_dir / f"{name}.csv").exists())
WarningInterpretation matters

A dataset extract is only useful when its selection criteria are reproducible and its limitations understood. In your notebook, distinguish missing from zero, a percentage from a proportion, and an assignment-defined category from a real-world clinical or financial risk classification.
