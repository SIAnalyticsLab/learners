Use this compact reference after the quiz to consolidate the syntax patterns you should be able to recognize and apply without hesitation.

Selecting and renaming columns

  • select(age, sex) keeps named columns.
  • select(age:occupation) keeps a consecutive range.
  • select(!age) excludes one column.
  • select(!c(age, sex)) excludes non-consecutive columns.
  • starts_with(), ends_with(), and contains() select by name pattern.
  • select(starts_with("is_"), everything()) reorders without dropping the remaining columns.
  • rename(patient_age = age) follows new name = old name.

Filtering rows

  • filter(sex == "Male") keeps rows meeting an equality condition.
  • Use <, <=, >, >=, ==, and != for relational tests.
  • %in% is efficient when one variable may match several allowed values.
  • & means both conditions must be TRUE. | means either condition may be TRUE.
  • !() negates a condition and is useful for “NOT in” logic.
  • is.na(x) identifies missing values. !is.na(x) keeps non-missing values.
  • When needed, explicitly preserve missing rows in compound filtering conditions.
Core mental model: use select() to decide which variables you keep, and use filter() to decide which observations you keep.
